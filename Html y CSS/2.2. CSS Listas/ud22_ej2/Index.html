Módulos del Ciclo Formativo CFGS DAM

  • Sistemas Informáticos: instalación, configuración y mantenimiento de sistemas operativos en red y arquitecturas de hardware.
  • Bases de Datos: diseño conceptual, lógico y físico utilizando lenguaje SQL en SGBD relacionales y no relacionales.
  • Programación: desarrollo de aplicaciones orientadas a objetos utilizando Java, estructuras de datos avanzadas y gestión de excepciones.
  • Lenguajes de Marcas y Sistemas de Gestión de Información: creación de documentos web estructurados con HTML5, validación XML y hojas de estilo CSS3.
  • Entornos de Desarrollo: utilización de entornos integrados de desarrollo, control de versiones con Git y pruebas unitarias.

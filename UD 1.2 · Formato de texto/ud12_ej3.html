Ficha técnica de Python

Información general

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general.

Python puede utilizarse para desarrollar aplicaciones, automatizar tareas, analizar datos y crear diferentes tipos de programas.

IDE es la abreviatura utilizada para referirse a un entorno de desarrollo integrado. 

print("Hola, mundo")
